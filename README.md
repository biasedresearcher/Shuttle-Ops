# Shuttle-Ops
Pastel-powered badminton match tracker with daily, weekly, and monthly leaderboards.

## Features
- Record singles or doubles matches with winner selection
- Daily, weekly, monthly, and all-time leaderboards (rank movement shown for daily)
- Undo/edit/delete recent matches
- Stats cards: win %, streaks, total matches, recent form, head-to-head
- Highlights: most active, most improved this month, player of the week
- Badges and achievement popups for milestones

## Getting started
```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.
